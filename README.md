# Python Essentials

Course materials for **Python Essentials**.

## Repository layout

| Folder | Contents |
| --- | --- |
| `modules/` | Lesson content, organized by module |
| `labs/` | Hands-on lab exercises and starter code |
| `solutions/` | Reference solutions for labs |
| `resources/` | Slides, cheat sheets, datasets, and supplementary material |

## Getting started

```bash
git clone https://github.com/santigrey/Python-Essentials.git
cd Python-Essentials
python3 -m venv .venv
source .venv/bin/activate
```
