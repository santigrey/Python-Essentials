# ALAB 356.4 - Generators, Closures, and Utility Modules

**Name:** James Sloan
**Course:** Python Essentials (UCI 3052)
**Date:** September 13, 2026

Four small scripts covering a Fibonacci generator, a closure factory, a
timestamped diary with file I/O, and a calendar/date utility.

## Files

| File | Purpose |
| --- | --- |
| `fibonacci_generator.py` | Task 1 — `gen_fibonacci(n)` yields the first `n` Fibonacci numbers, one at a time. |
| `multiplier_closure.py` | Task 2 — `make_multiplier(factor)` returns a closure; each closure it makes remembers its own factor. |
| `diary.py` | Task 3 — checks whether `diary.txt` exists (creating it if not), appends timestamped entries, then displays the file. |
| `calendar_utility.py` | Task 4 — prints a month's calendar via the `calendar` module and reports whether today falls inside it. |
| `diary.txt` | Generated by `diary.py` — sample diary content from the two runs below. |
| `ALAB-356.4-Canvas-Submission.pdf` | The one-page PDF submitted to Canvas — direct clickable links to each script. |
| `ALAB-356.4-output-logs.md` | Captured terminal transcripts for all four scripts, both diary runs, and all four calendar runs. |
| `screenshot-1-fibonacci_generator.png`<br>`screenshot-2-multiplier_closure.png`<br>`screenshot-3a-diary-create.png`<br>`screenshot-3b-diary-append.png`<br>`screenshot-4a-calendar_utility-within.png`<br>`screenshot-4b-calendar_utility-not-within.png` | Terminal screenshots of each script running. |

## How to run

```bash
cd "modules/Module 356/ALAB 356.4"
python3 fibonacci_generator.py
python3 multiplier_closure.py
python3 diary.py
python3 calendar_utility.py
```

Python 3.9 or newer. No third-party packages. `diary.py` and
`calendar_utility.py` ask for input; the other two run a fixed
demonstration.
